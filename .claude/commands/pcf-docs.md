Display PCF documentation for a specific topic.

Arguments: $ARGUMENTS

## Available topics

| Argument | Content |
|---|---|
| `init` | Prerequisites, scaffold, ControlManifest, Dataverse types |
| `coding` | Lifecycle methods, full context API (parameters, mode, formatting, navigation, device) |
| `dataset` | Grid controls, pagination, filtering, sorting, selection |
| `webapi` | Dataverse CRUD: create, retrieve, update, delete |
| `react` | Virtual/React components with Fluent UI 8 and 9 |
| `build` | Build, PCF test harness debug, common errors |
| `packaging` | Solution packaging, deployment, CI/CD |

## What you must do

1. If a topic is provided in the arguments, read
   `.claude/skills/pcf/references/0X-<topic>.md` directly.

2. If no argument is given, list the topics and ask which one to display.

3. Present the content clearly with relevant code examples.
